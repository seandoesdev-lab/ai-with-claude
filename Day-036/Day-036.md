## 0. 들어가며 (Motivation)

우리는 [[Day-026]] 에서 신경망의 **순전파**(입력→은닉→출력)를, [[Day-027]] 에서 **역전파**(연쇄법칙으로 기울기를 거꾸로 흘리기)를 배웠고, [[Day-028]]·[[Day-029]] 에서 PyTorch 의 **autograd** 가 그 역전파를 **자동으로** 해 주는 것을 봤습니다. 편했죠. 그런데 편한 만큼 **블랙박스** 이기도 합니다 — `loss.backward()` 한 줄 뒤에서 정확히 무슨 미분이 일어나는지는 가려져 있습니다.

🛠️ 빌드 트랙의 원칙은 **"동작이 우선, 처음부터 직접"** 입니다([[Day-014]] B1, [[Day-021]] B2 와 같은 결). 오늘은 autograd 를 걷어내고 `dW1, db1, dW2, db2` 를 **손으로** 계산합니다. 이렇게 한 번 만들어 보면, [[Day-035]] 에서 읽은 Transformer 의 학습도 결국 **같은 연쇄법칙의 반복** 임이 손끝으로 이해됩니다.

데이터는 일부러 **나선형(spiral)** 을 씁니다. 직선 하나로는 두 갈래를 절대 못 가르죠([[Day-010]] 의 선형 베이스라인이 못 넘던 벽). **은닉층 + 비선형(ReLU)** 이 있어야 굽은 경계를 그릴 수 있다 — MLP 가 왜 필요한지를 데이터가 스스로 보여 줍니다.

> We built forward passes (Day-026) and backprop (Day-027), then let PyTorch's autograd do backprop for us (Day-028). Today we turn autograd off and hand-code the gradients in NumPy — a mini MLP that classifies a non-linearly-separable spiral (acc 0.995) — and we *prove* our backprop is correct with a gradient check (relative error ~1e-8). ## 1. 핵심 개념 (Core Concepts)

우리가 만들 모델은 **2 → 16 → 2** 짜리 아주 작은 MLP 입니다: 입력 2차원(점의 x,y), 은닉 16 뉴런(ReLU), 출력 2클래스(softmax). 학습은 **softmax + 교차엔트로피(cross-entropy)** 손실을 **전량 경사하강법(full-batch GD)** 으로 줄입니다.

### 1.1 순전파 (Forward) — 4개의 식 ([[Day-026]])

$$
z_1 = XW_1 + b_1,\quad a_1 = \mathrm{ReLU}(z_1),\quad
z_2 = a_1 W_2 + b_2,\quad P = \mathrm{softmax}(z_2)
$$

- `X`: `(N,2)` 입력 배치, `W1`: `(2,16)`, `W2`: `(16,2)`.
- **ReLU** `max(0,z)` 가 비선형성을 넣습니다 — 이게 없으면 선형변환 2번은 결국 1번(선형)이라 나선형을 못 가릅니다.
- **softmax** 가 로짓(logit) `z2` 를 확률 `P` 로 바꿉니다([[Day-013]]·[[Day-027]]).

### 1.2 손실 (Loss) — 교차엔트로피

$$
L = -\frac{1}{N}\sum_{n} \log P_{n,\,y_n}
$$

정답 클래스에 매긴 확률이 1 에 가까울수록 손실이 0 에 가까워집니다.

### 1.3 역전파 (Backward) — 연쇄법칙을 손으로 ([[Day-027]])

역전파의 핵심은 **출력 쪽 기울기에서 입력 쪽으로** 곱해 내려오는 것입니다. 반가운 지름길 하나: **softmax + cross-entropy 를 묶으면** 미분이 놀랍도록 깔끔합니다.

$$
\frac{\partial L}{\partial z_2} = \frac{1}{N}\,(P - \mathbf{1}_{y})
$$

여기서 `1_y` 는 정답을 1 로 하는 원-핫입니다. 이제 이 `dz2` 를 시작으로 층을 거슬러 올라갑니다:

| 단계 | 식 | 모양 |
|------|-----|------|
| 출력 로짓 | `dz2 = (P − onehot)/N` | `(N,2)` |
| 2층 가중치 | `dW2 = a1ᵀ · dz2` | `(16,2)` |
| 2층 편향 | `db2 = Σ dz2` | `(2,)` |
| 은닉 활성 | `da1 = dz2 · W2ᵀ` | `(N,16)` |
| ReLU 통과 | `dz1 = da1 ⊙ (z1 > 0)` | `(N,16)` |
| 1층 가중치 | `dW1 = Xᵀ · dz1` | `(2,16)` |
| 1층 편향 | `db1 = Σ dz1` | `(16,)` |

**ReLU 의 미분** 이 `(z1 > 0)` 마스크로 나타나는 게 포인트입니다 — 0 이하였던 뉴런은 기울기를 **차단**(gate)합니다.

### 1.4 왜 gradient check 인가 — "내 미분이 맞다"의 증명

손으로 유도한 식은 **틀리기 쉽습니다**(전치 빠뜨림, `/N` 실수 등). 그래서 **수치 미분** 으로 대조합니다. 정의상 미분은

$$
\frac{\partial L}{\partial \theta} \approx \frac{L(\theta+\varepsilon) - L(\theta-\varepsilon)}{2\varepsilon}\quad(\text{중심차분})
$$

파라미터 하나를 아주 살짝 흔들어 손실 변화를 직접 재는 것입니다. 이 **수치 기울기** 와 우리의 **해석 기울기** 의 상대오차가 `1e-6~1e-8` 수준이면, 역전파가 정확하다는 강력한 증거입니다. (느려서 학습엔 못 쓰고 **검증용**.)

## 2. 직관 / 비유 (Intuition)

> [!tip] 비유 — autograd 는 '자동 변속기', 오늘은 '수동 변속기'로 직접 운전
> PyTorch autograd([[Day-028]])는 **자동 변속기** 입니다 — 클러치·기어를 신경 안 써도 차가 굴러가죠. 오늘 우리가 하는 건 **수동 변속기로 직접 운전** 하는 것입니다. 순전파에서 각 중간값(`z1, a1, z2, P`)을 **기억(cache)** 해 두었다가, 역전파에서 그 기억을 거꾸로 짚으며 기어(기울기)를 한 단씩 내립니다. 한 번 수동으로 몰아 보면, 자동 변속기가 뒤에서 **정확히 무슨 일** 을 하는지(어떤 기어에서 어떤 토크가 나오는지) 몸으로 알게 됩니다. 그리고 gradient check 는 **계기판으로 실제 속도를 재보는 것** — 내가 넣은 기어가 맞았는지 숫자로 확인하는 절차죠.
>
> Autograd is an automatic transmission; today we drive stick. The forward pass caches every intermediate (`z1,a1,z2,P`); the backward pass walks those memories in reverse, shifting gears (gradients) down one layer at a time. Driving stick once tells you exactly what the automatic was doing — and the gradient check is the speedometer that confirms you shifted correctly.

## 3. 한 장의 그림 (One Picture)

```text
   NumPy MLP (2 → 16 → 2) — 순전파 캐시 → 역전파 → 검증
   ────────────────────────────────────────────────────
   FORWARD  (값을 앞으로, 중간값은 cache에 저장)
     X ──W1,b1──▶ z1 ──ReLU──▶ a1 ──W2,b2──▶ z2 ──softmax──▶ P ──▶ L(CE)
     └─cache─────┘  └─cache──┘             └cache┘        └cache┘

   BACKWARD (기울기를 거꾸로, 연쇄법칙)   [[Day-027]]
     dL/dz2 = (P − onehot)/N
        │  dW2 = a1ᵀ·dz2 ,  db2 = Σdz2
        ▼
     da1 = dz2·W2ᵀ  ──⊙(z1>0)──▶ dz1     ← ReLU'가 죽은 뉴런을 차단
        │  dW1 = Xᵀ·dz1 ,  db1 = Σdz1
        ▼
     θ ← θ − lr·dθ        (full-batch gradient descent)

   VERIFY   해석적 dθ  ≟  수치적 (L(θ+ε)−L(θ−ε))/2ε
            └──▶ 상대오차 1.37e-08  ✅  (backprop 정확)
```

> Forward stores intermediates in a cache; backward replays them in reverse with the chain rule (ReLU' gates dead neurons); gradient descent updates θ; a gradient check confirms the analytic gradients match numerical ones (rel. error 1.37e-8).

## 4. 실습 (Hands-on) — MLP + 역전파 from scratch

> 환경: **Windows + PowerShell**, 실행 **uv**, **NumPy만**. 전체 코드는 옆 파일 **`mlp_from_scratch.py`**.

### 4.1 실행

```powershell
# Day-002 의 uv 프로젝트에서
uv add numpy            # 이미 있으면 생략
# 한글이 깨지면 먼저: $env:PYTHONIOENCODING="utf-8"
uv run python mlp_from_scratch.py
# (uv 프로젝트에 numpy가 없으면) uv run --with numpy python mlp_from_scratch.py
```

### 4.2 순전파 + 캐시 (핵심 발췌)

```python
def forward(params, X):
    z1 = X @ params["W1"] + params["b1"]     # (N,16) 선형
    a1 = relu(z1)                            # (N,16) 비선형(ReLU)
    z2 = a1 @ params["W2"] + params["b2"]    # (N,2)  로짓
    probs = softmax(z2)                      # (N,2)  확률
    cache = {"X": X, "z1": z1, "a1": a1, "probs": probs}
    return probs, cache
```

### 4.3 역전파 — 손으로 유도한 4개 기울기

```python
def backward(params, cache, y):
    X, a1, probs = cache["X"], cache["a1"], cache["probs"]
    n = y.shape[0]
    dz2 = probs.copy(); dz2[np.arange(n), y] -= 1.0; dz2 /= n   # (P−onehot)/N
    dW2 = a1.T @ dz2                         # (16,2)
    db2 = dz2.sum(axis=0)                    # (2,)
    da1 = dz2 @ params["W2"].T               # (N,16)
    dz1 = da1 * (cache["z1"] > 0)            # ReLU': z>0 → 1
    dW1 = X.T @ dz1                          # (2,16)
    db1 = dz1.sum(axis=0)                    # (16,)
    return {"W1": dW1, "b1": db1, "W2": dW2, "b2": db2}
```

### 4.4 학습 결과 (재현 가능)

```
[데이터] 나선형 2-class: X=(200, 2), y=(200,) (선형 분리 불가)

[학습] MLP(2 -> 16 -> 2), ReLU, softmax-CE, full-batch GD, lr=1.0
  epoch    1:  loss=0.6311   train_acc=0.500
  epoch  400:  loss=0.0452   train_acc=0.990
  epoch  800:  loss=0.0290   train_acc=0.995
  epoch 1200:  loss=0.0232   train_acc=0.995
  epoch 1600:  loss=0.0200   train_acc=0.995
  epoch 2000:  loss=0.0180   train_acc=0.995

[결과] 최종 train accuracy = 0.995
```

시작할 때(epoch 1) 정확도가 딱 **0.500** — 동전 던지기 수준입니다(두 클래스를 못 가름). 그런데 손코딩한 역전파로 기울기를 흘려 주기 시작하자 손실이 `0.63 → 0.018` 로 급락하고, 정확도는 **0.995** 까지 올라갑니다. **은닉층 없이 선형만으로는 절대 못 넘는 벽** 을, ReLU 은닉층 하나가 넘어섭니다.

### 4.5 기울기 검증 — 내 미분이 맞다는 증명

```
[검증] gradient check 최대 상대오차 = 1.37e-08  -> 1e-6 수준이면 backprop 정확 (OK)
```

수치 미분(`(L(θ+ε)−L(θ−ε))/2ε`)과 우리의 해석적 기울기가 **소수점 8자리** 까지 일치합니다. 이 한 줄이 "손으로 유도한 `dW1, dW2, ...` 가 전부 맞다"를 보증합니다 — autograd 없이도 **정확히** 학습했다는 뜻입니다.

### 4.6 (실험) 직접 흔들어 보기

- **ReLU 지우기**: `forward` 에서 `a1 = z1`(비선형 제거)로 두면, 아무리 학습해도 정확도가 **0.5 근처** 에 머뭅니다 — 왜 나선형에 비선형이 **필수** 인지 눈으로 확인.
- **은닉 폭 바꾸기**: `d_hidden=2` 로 줄이면 경계가 거칠어지고, `64` 로 늘리면 부드러워집니다.
- **학습률 키우기**: `lr=5.0` 으로 올려 손실이 **발산(NaN)** 하는지 관찰 — 경사하강의 안정성([[Day-027]]).
- **`/N` 빼먹기**: `backward` 에서 `dz2 /= n` 줄을 지우면 gradient check 상대오차가 **커집니다** — 검증이 실수를 어떻게 잡아내는지 체험.

## 6. 생각거리 (Reflection)

> [!question] 스스로 답해 보기
> 1. **왜 비선형이 필수인가.** ReLU 를 없애면(선형만) 층을 아무리 쌓아도 하나의 선형변환과 같습니다. 이를 수식으로 보이고, 4.6 의 "ReLU 지우기" 실험 결과(정확도 0.5)와 연결해 보세요.
> 2. **softmax-CE 결합미분.** 왜 `dL/dz2 = (P − onehot)/N` 이라는 깔끔한 식이 나올까요? softmax 와 cross-entropy 를 따로 미분했을 때보다 왜 이게 편할까요? ([[Day-027]])
> 3. **gradient check 의 신뢰.** 상대오차가 `1e-8` 이면 안심이고 `1e-2` 면 의심입니다. 왜 정확히 0 이 아니라 아주 작은 값이 나올까요(ε·부동소수점)? 이 검증을 통과했다는 게 autograd([[Day-028]])와 무슨 관계일까요?

## 7. 오늘의 한 줄 요약 (Takeaway)

> [!summary]
> **PyTorch autograd 를 끄고, [[Day-026]] 순전파 + [[Day-027]] 역전파(연쇄법칙)를 NumPy만으로 손코딩해 2→16→2 MLP 를 만들었다.** 선형 분리 불가능한 나선형 데이터를 정확도 **0.995** 로 분류했고(선형만으론 0.5), 핵심은 ① softmax-CE 결합미분 `dL/dz2=(P−onehot)/N` 에서 출발해 `dW2=a1ᵀdz2 → da1=dz2·W2ᵀ → dz1=da1⊙(z1>0) → dW1=Xᵀdz1` 로 층을 거슬러 기울기를 흘리고, ② **gradient check** 로 해석적 기울기가 수치미분과 상대오차 **1.37e-8** 로 일치함을 증명해 "내 역전파가 맞다"를 숫자로 확인했다. autograd 가 뒤에서 하는 일을 손으로 재현한 것 — 다음 편([[Day-037]])은 이 위에 PyTorch 로 🛠️ **미니 Transformer(마스킹 self-attention)** 를 얹어 B3 빌드를 완성한다.
